# Smart Lost & Found Management System

## 1. Problem Statement

In schools, colleges, universities, and other organizations, students and staff frequently lose personal belongings such as ID cards, wallets, watches, calculators, books, and electronic devices. Managing lost and found items manually can make it difficult to report items, search for them, identify their owners, and track claims.

The Smart Lost & Found Management System aims to provide a centralized platform where users can report lost and found items, search for reported items, and identify possible matches between lost and found records. The system uses a smart weighted matching mechanism to compare item details and provide suitable match suggestions.

The project focuses on making the lost and found process simple, organized, and efficient while demonstrating Java programming concepts and database management.

## 2. Scope of the Project

The scope of the Smart Lost & Found Management System includes the development of a platform with modules for user management, lost item reporting, found item reporting, item searching, smart matching, claim management, and administrative management.

The system includes a Java-based backend implementation using Servlets, JDBC, MySQL, and a smart weighted matching engine.

The matching system compares important item attributes such as category, item name, location, color, brand, date, and description to calculate a matching score.

The current project is mainly intended for academic and demonstration purposes. It uses sample or simulated lost and found information and is not intended to replace an enterprise-level property recovery system.

## 3. Target Users

The system is designed for users who may be involved in lost and found management activities, including:

- Students
- Faculty and teaching staff
- College or school employees
- Administrative staff
- System administrators
- Security or help-desk staff
- Students and academic users for demonstration and learning
